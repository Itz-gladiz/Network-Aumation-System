# Network-Aumation-System
A full-stack Network Management Automation and DevOps platform built with React, Django REST Framework, PostgreSQL, and Netmiko for centralized device management, SSH automation, configuration backup, deployment, monitoring, and activity logging.
# NetDevOps

NetDevOps is a full-stack Network Management Automation and DevOps platform designed to simplify the management of network infrastructure. It provides a centralized web interface for managing Cisco, MikroTik, and DD-WRT devices, automating configuration backups, deploying configurations, monitoring device status, and maintaining activity logs.

## Features

- Device Inventory Management
- SSH Connectivity Testing
- Automated Configuration Backup
- Configuration Deployment
- Dashboard with Real-Time Statistics
- User Authentication (JWT)
- Role-Based Access Control (Administrator, Engineer, Viewer)
- Activity Logging
- Configuration Templates
- Network-based Device Organization
- Backup History
- Deployment History
